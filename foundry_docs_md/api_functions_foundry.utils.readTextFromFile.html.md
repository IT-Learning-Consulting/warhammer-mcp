# readTextFromFile

```typescript
readTextFromFile(file: File): Promise<string>
```

Read text data from a user provided File object.

## Parameters

- **file**: `File`  
  A File object.

## Returns

`Promise<string>`  
A Promise which resolves to the loaded text data.
