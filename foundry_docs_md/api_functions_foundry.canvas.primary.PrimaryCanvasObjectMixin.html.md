# PrimaryCanvasObjectMixin | Foundry Virtual Tabletop - API Documentation - Version 13

### Function `PrimaryCanvasObjectMixin`

```typescript
PrimaryCanvasObjectMixin(DisplayObject: typeof DisplayObject): any
```

A mixin which decorates a `DisplayObject` with additional properties expected for rendering in the `PrimaryCanvasGroup`.

#### Parameters

- **DisplayObject**: `typeof DisplayObject`  
  The parent `DisplayObject` class being mixed.

#### Returns

- `any`  
  A `DisplayObject` subclass mixed with `PrimaryCanvasObject` features.
