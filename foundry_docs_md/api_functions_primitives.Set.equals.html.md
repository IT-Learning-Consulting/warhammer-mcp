### Function `equals`

```typescript
equals(other: Set<any>): boolean
```

Test whether this set is equal to some other set. Sets are equal if they share the same members, independent of order.

**Parameters**

- **other**: `Set<any>`  
  Some other set to compare against

**Returns** `boolean`  
Are the sets equal?
