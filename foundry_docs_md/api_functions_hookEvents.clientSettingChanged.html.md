# clientSettingChanged

```typescript
clientSettingChanged(key: string, value: any, options: object): void
```

A hook event that fires when a client setting changes.

### Parameters

- **key**: `string`  
  The setting key which changed
- **value**: `any`  
  The new setting value
- **options**: `object`  
  Additional options passed with the request

### Returns

`void`
