# DocumentSheetConfigFieldDescriptor

## Interface

```typescript
interface DocumentSheetConfigFieldDescriptor {
    disabled?: boolean;
    field: DataField;
    name: string;
    value: string;
}
```

## Properties

- **disabled?**: `boolean`  
  Whether the field should be disabled in the form.

- **field**: `DataField`  
  The field instance.

- **name**: `string`  
  The field's form name.

- **value**: `string`  
  The field's value.
