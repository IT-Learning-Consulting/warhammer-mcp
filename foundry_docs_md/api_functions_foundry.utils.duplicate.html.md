# duplicate

```typescript
duplicate(original: Object): any
```

A cheap data duplication trick which is relatively robust. For a subset of cases the `deepClone` function will offer better performance.

**Parameters**

- **original**: *Object*  
  Some sort of data

**Returns** *any*
