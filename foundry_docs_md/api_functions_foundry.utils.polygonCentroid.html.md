### Function `polygonCentroid`

```typescript
polygonCentroid(points: number[] | Point[]): Point
```

Calculate the centroid of a non-self-intersecting closed polygon. See [https://en.wikipedia.org/wiki/Centroid#Of_a_polygon](https://en.wikipedia.org/wiki/Centroid#Of_a_polygon).

**Parameters**

- **points**: `number[] | Point[]`  
  The points of the polygon

**Returns**

`Point`  
The centroid of the polygon
