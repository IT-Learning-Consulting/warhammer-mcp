# PingOptions

```typescript
interface PingOptions {
    color?: string;
    duration?: number;
    name?: string;
    size?: number;
}
```

## Properties

- **color?**: *string*  
  The color of the ping graphic.

- **duration?**: *number*  
  The duration of the animation in milliseconds.

- **name?**: *string*  
  The name for the ping animation to pass to [foundry.canvas.animation.CanvasAnimation.animate](https://foundryvtt.com/api/classes/foundry.canvas.animation.CanvasAnimation.html#animate).

- **size?**: *number*  
  The size of the ping graphic.
