# isValid | Foundry Virtual Tabletop - API Documentation - Version 13

### Function `isValid`

```typescript
isValid(): boolean
```

Test whether a `Date` instance is valid. A valid date returns a number for its timestamp, and `NaN` otherwise. `NaN` is never equal to itself.

**Returns**  
`boolean`
