# getRoute | Foundry Virtual Tabletop - API Documentation - Version 13

```typescript
getRoute(path: string, prefix?: null | string): string
```

Get the URL route for a certain path which includes a path prefix, if one is set.

**Parameters**

- **path**: `string`  
  The Foundry URL path

- **prefix**: `null | string` = {} (Optional)  
  A path prefix to apply

**Returns**  
`string`  
The absolute URL path
