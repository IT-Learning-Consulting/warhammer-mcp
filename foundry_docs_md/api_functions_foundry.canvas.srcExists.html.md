# srcExists

## Function srcExists

```typescript
srcExists(src: string): Promise<boolean>
```

Test whether a file source exists by performing a HEAD request against it.

### Parameters

- **src**: `string`  
  The source URL or path to test.

### Returns

`Promise<boolean>`  
Does the file exist at the provided URL?
