```typescript
rtcSettingsChanged(settings: AVSettings, changed: object): void
```

A hook event that fires when the AV settings are changed.

**Parameters**

- **settings**: [AVSettings](https://foundryvtt.com/api/classes/foundry.av.AVSettings.html)  
  The AVSettings manager

- **changed**: `object`  
  The delta of the settings that have been changed

**Returns**  
`void`
