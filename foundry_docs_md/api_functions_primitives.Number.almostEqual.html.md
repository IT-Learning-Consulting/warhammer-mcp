# almostEqual

```typescript
almostEqual(n: number, e?: number): boolean
```

Test for near-equivalence of two numbers within some permitted epsilon.

**Parameters**

- **n**: *number*  
  Some other number

- **e**: *number* = 1e-8  
  Some permitted epsilon, by default 1e-8

**Returns**  
*boolean*  
Are the numbers almost equal?
