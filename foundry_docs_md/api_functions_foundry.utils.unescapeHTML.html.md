# unescapeHTML | Foundry Virtual Tabletop - API Documentation - Version 13

### Function `unescapeHTML`

```typescript
unescapeHTML(value: string): string
```

Unescape the given escaped string.

Handles only `&amp;`, `&lt;`, `&gt;`, `&quot;`, and `&#x27;`.

**Parameters**

- **value**: *string*  
  An escaped string

**Returns**  
*string*  
The escaped string
