# extendPIXIGraphics | Foundry Virtual Tabletop - API Documentation - Version 13

### Function `extendPIXIGraphics`

```typescript
extendPIXIGraphics(): void
```

Extend `PIXI.Graphics`/`SmoothGraphics` with new methods **AND** replace `PIXI.Graphics` by `SmoothGraphics`. The original `PIXI.Graphics` is put into `PIXI.LegacyGraphics`.

**Returns:** `void`
