# TABLE_RESULT_TYPES | Foundry Virtual Tabletop - API Documentation - Version 13

**Variable** `TABLE_RESULT_TYPES` Const

```typescript
TABLE_RESULT_TYPES: { DOCUMENT: "document"; TEXT: "text" } = ...
```

The allowed types of a TableResult document

## Type declaration

- **Readonly**

- **DOCUMENT**: `"document"`  
  An in-World Document reference which will be linked to in the chat message.

- **Readonly**

- **TEXT**: `"text"`  
  Plain text or HTML scripted entries which will be output to Chat.
