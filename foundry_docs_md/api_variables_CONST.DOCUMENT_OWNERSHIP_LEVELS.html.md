# DOCUMENT_OWNERSHIP_LEVELS | Foundry Virtual Tabletop - API Documentation - Version 13

```typescript
const DOCUMENT_OWNERSHIP_LEVELS: Readonly<{
    INHERIT: -1;
    LIMITED: 1;
    NONE: 0;
    OBSERVER: 2;
    OWNER: 3;
}> = ...
```

Define the allowed ownership levels for a Document. Each level is assigned a value in ascending order. Higher levels grant more permissions.
