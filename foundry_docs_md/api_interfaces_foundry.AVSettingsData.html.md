# AVSettingsData

```typescript
interface AVSettingsData {
    hidden?: boolean;
    muted?: boolean;
    speaking?: boolean;
}
```

## Properties

### hidden?  
*Type:* `boolean`  
Whether this user has hidden their video.

### muted?  
*Type:* `boolean`  
Whether this user has muted themselves.

### speaking?  
*Type:* `boolean`  
Whether the user is broadcasting audio.
