# GridOffset3D

3D offset coordinates of a grid space.

```typescript
interface GridOffset3D {
    i: number;
    j: number;
    k: number;
}
```

## Properties

- **i**: `number`  
  The row coordinate (an integer)

- **j**: `number`  
  The column coordinate (an integer)

- **k**: `number`  
  The vertical coordinate (an integer)
