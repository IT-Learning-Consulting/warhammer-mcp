# initializePriorityLightSources | Foundry Virtual Tabletop - API Documentation - Version 13

### Function `initializePriorityLightSources`

```typescript
initializePriorityLightSources(group: EffectsCanvasGroup): void
```

A hook event that fires after priority light sources initialization. This hook can be used to add specific behaviors for edge sources to the Scene.

**Parameters**

- **group**: [EffectsCanvasGroup](https://foundryvtt.com/api/classes/foundry.canvas.groups.EffectsCanvasGroup.html)  
  The EffectsCanvasGroup where priority sources are initialized

**Returns**  
`void`
