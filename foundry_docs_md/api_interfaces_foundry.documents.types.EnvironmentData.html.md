# EnvironmentData

```typescript
interface EnvironmentData {
    hue?: number;
    intensity?: number;
    luminosity?: number;
    saturation?: number;
    shadows?: number;
}
```

## Properties

- **hue?**: `number`  
  The normalized hue angle.

- **intensity?**: `number`  
  The intensity of the tinting (0 = no tinting).

- **luminosity?**: `number`  
  The luminosity.

- **saturation?**: `number`  
  The saturation.

- **shadows?**: `number`  
  The strength of the shadows.
