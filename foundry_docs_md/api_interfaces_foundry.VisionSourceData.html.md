# VisionSourceData | Foundry Virtual Tabletop - API Documentation - Version 13

## Interface VisionSourceData

```typescript
interface VisionSourceData {
    attenuation: number;
    blinded: boolean;
    brightness: number;
    contrast: number;
    lightRadius: number;
    saturation: number;
    visionMode: string;
}
```

## Properties

- **attenuation**: `number`  
  Strength of the attenuation between bright, dim, and dark

- **blinded**: `boolean`  
  Is this vision source blinded?

- **brightness**: `number`  
  The vision brightness.

- **contrast**: `number`  
  The amount of contrast

- **lightRadius**: `number`  
  The range of light perception.

- **saturation**: `number`  
  The amount of color saturation

- **visionMode**: `string`  
  The vision mode.
