# GridMeshData

The grid mesh data.

```typescript
interface GridMeshData {
    alpha: number;
    color: number;
    height: number;
    size: number;
    thickness: number;
    type: number;
    width: number;
}
```

## Properties

- **alpha**: `number`  
  The alpha of the grid

- **color**: `number`  
  The color of the grid

- **height**: `number`  
  The height of the grid in pixels

- **size**: `number`  
  The size of a grid space in pixels

- **thickness**: `number`  
  The thickness of the grid lines in pixels

- **type**: `number`  
  The type of the grid (see [CONST.GRID_TYPES](https://foundryvtt.com/api/variables/CONST.GRID_TYPES.html))

- **width**: `number`  
  The width of the grid in pixels
