# fromRange

```typescript
fromRange(n: number, min?: number): number[]
```

Create and initialize an array of length `n` with integers from `min` to `min + n - 1`.

**Parameters**

- **n**: `number`  
  The desired array length

- **min**?: `number` = 0  
  A desired minimum number from which the created array starts

**Returns**  
`number[]`  
An array of integers from `min` to `min + n - 1`
