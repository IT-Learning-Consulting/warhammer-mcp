# dropRollTableSheetData

## Function dropRollTableSheetData

```typescript
dropRollTableSheetData(
    table: documents.RollTable,
    sheet: RollTableSheet,
    data: object,
): void
```

A hook event that fires when some useful data is dropped onto a RollTableSheet.

### Parameters

- **table**: [`documents.RollTable`](https://foundryvtt.com/api/modules/foundry.documents.html#RollTable)  
  The RollTable

- **sheet**: [`RollTableSheet`](https://foundryvtt.com/api/classes/foundry.applications.sheets.RollTableSheet.html)  
  The RollTableConfig application

- **data**: `object`  
  The data dropped onto the RollTableSheet

### Returns

`void`
