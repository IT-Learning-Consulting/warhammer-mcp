# ElevatedPoint | Foundry Virtual Tabletop - API Documentation - Version 13

## Interface ElevatedPoint

A 3D point, expressed as `{x, y, elevation}`.

```typescript
interface ElevatedPoint {
    elevation: number;
    x: number;
    y: number;
}
```

## Properties

- **elevation**: *number*  
  The elevation in grid units

- **x**: *number*  
  The x-coordinate in pixels

- **y**: *number*  
  The y-coordinate in pixels
