# fields

Namespace **fields**

This module contains data field classes which are used to define a data schema. A data field is responsible for cleaning, validation, and initialization of the value assigned to it. Each data [field extends the foundry.data.fields.DataField class to implement logic specific to its contained data type.](https://foundryvtt.com/api/classes/foundry.data.fields.DataField.html)
