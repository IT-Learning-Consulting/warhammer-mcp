# USER_ROLES | Foundry Virtual Tabletop - API Documentation - Version 13

**Variable USER_ROLES Const**

```typescript
USER_ROLES: Readonly<{
    ASSISTANT: 3;
    GAMEMASTER: 4;
    NONE: 0;
    PLAYER: 1;
    TRUSTED: 2;
}> = ...
```

Define the allowed User permission levels. Each level is assigned a value in ascending order. Higher levels grant more permissions.
