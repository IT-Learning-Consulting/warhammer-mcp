### Function `CanvasTransformMixin`

```typescript
CanvasTransformMixin(
    DisplayObject: typeof DisplayObject,
): (DisplayObject: typeof DisplayObject) => typeof CanvasTransformMixin
```

A mixin which decorates a `DisplayObject` with additional properties for canvas transforms and bounds.

#### Parameters

- **DisplayObject**: `typeof DisplayObject`  
  The parent `DisplayObject` class being mixed.

#### Returns

- `(DisplayObject: typeof DisplayObject) => typeof CanvasTransformMixin`  
  A `DisplayObject` subclass mixed with `CanvasTransformMixin` features.
