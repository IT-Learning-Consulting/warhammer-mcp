### Function `collapseSceneNavigation`

```typescript
collapseSceneNavigation(app: SceneNavigation, collapsed: boolean): void
```

- **app**: [SceneNavigation](https://foundryvtt.com/api/classes/foundry.applications.ui.SceneNavigation.html)

- **collapsed**: `boolean`
