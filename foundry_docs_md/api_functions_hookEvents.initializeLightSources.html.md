# initializeLightSources | Foundry Virtual Tabletop - API Documentation - Version 13

### Function initializeLightSources

```typescript
initializeLightSources(group: EffectsCanvasGroup): void
```

A hook event that fires during light source initialization. This hook can be used to add programmatic light sources to the Scene.

**Parameters**

- **group**: _EffectsCanvasGroup_  
  The EffectsCanvasGroup where light sources are initialized

**Returns**

- _void_
