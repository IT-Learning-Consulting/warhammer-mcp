## Interface Rectangle

A standard rectangle interface.

```typescript
interface Rectangle {
    height: number;
    width: number;
    x: number;
    y: number;
}
```

## Properties

- **height**: *number*  
  The height

- **width**: *number*  
  The width

- **x**: *number*  
  The x-coordinate of the top-left corner

- **y**: *number*  
  The y-coordinate of the top-left corner
