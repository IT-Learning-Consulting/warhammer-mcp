# debug

**Variable** `debug` Const

Configure debugging flags to display additional information

```typescript
debug: {
    applications: boolean;
    audio: boolean;
    av: boolean;
    avclient: boolean;
    canvas: { primary: { bounds: boolean } };
    combat: boolean;
    dice: boolean;
    documents: boolean;
    fog: { extractor: boolean; manager: boolean };
    gamepad: boolean;
    hooks: boolean;
    i18n: boolean;
    keybindings: boolean;
    loader: {
        cache: boolean;
        eviction: boolean;
        load: boolean;
        memory: boolean;
    };
    mouseInteraction: boolean;
    polygons: boolean;
    queries: boolean;
    rollParsing: boolean;
    time: boolean;
} = ...
```
