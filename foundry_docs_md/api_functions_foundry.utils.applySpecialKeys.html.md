# applySpecialKeys

```typescript
applySpecialKeys(obj: any): any
```

Recurse through an object, applying all special keys. Deletion keys ("-=") are removed. Forced replacement keys ("==") are assigned.

**Parameters**

- **obj**: *any*

**Returns**

*any*
