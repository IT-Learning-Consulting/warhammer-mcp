# JournalEntryPageTitleData

```typescript
interface JournalEntryPageTitleData {
    level: number;
    show: boolean;
}
```

## Properties

- **level**: *number*  
  The heading level to render this page's title at in the overall journal view.

- **show**: *boolean*  
  Whether to render the page's title in the overall journal view.
